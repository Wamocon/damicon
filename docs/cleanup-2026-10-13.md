## Phase 4, Prävention

- **ESLint:** Komplexität über 40 und Funktionen über 400 Zeilen melden sich in `src` als Warnung. Der Lauf bricht nicht, die zentrale PR-Prüfung führt `npm run lint` ohne `--max-warnings` aus. Heute 11 Warnungen, das ist der sichtbare Rückstand (unten).
- **`npm run test:dubletten`** (Teil von `npm test` und damit der Build-Pipeline): jscpd mit Schwelle 0,1 Prozent, heute 0,06. Eine neue Kopie von rund 25 Zeilen oder mehr lässt den Test scheitern, das Log nennt die Fundstellen.
- **`npm run test:rechte`** (Teil von `npm test`): Jede exportierte Funktion einer `"use server"`-Datei und jeder Route Handler braucht eine erkennbare Prüfung. Bewusst öffentliche Wege stehen mit Grund in `OEFFENTLICH`. Exportformen, die das Skript nicht lesen kann (`export default`, `export { }`, Alias), werden gemeldet statt übergangen. Ein Negativtest mit einer absichtlich offenen Aktion hinter einem Kopfkommentar ist rot geworden.
- **`npm run qualitaet:ungenutzt`:** Bericht über ungenutzte Exporte und Dateien, kein Gate.
