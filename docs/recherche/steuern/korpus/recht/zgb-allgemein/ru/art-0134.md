# 134. Восстановление ценной бумаги

Восстановление прав по утраченным ордерным ценным бумагам производится судом в порядке, предусмотренном процессуальным законодательством.

Сноска. Статья 134 с изменением, внесенным Законом РК от 19.09.2025 № 219-VIII (вводится в действие по истечении шестидесяти календарных дней после дня его первого официального опубликования).
