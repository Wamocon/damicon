# 57. Прекращение деятельности юридического лица-банкрота

1. Признание судом юридического лица банкротом влечет его ликвидацию.

2. Деятельность юридического лица-банкрота считается прекращенной с момента исключения его из Национального реестра бизнес-идентификационных номеров.

Сноска. Статья 57 с изменением, внесенным Законом РК от 24.12.2012 № 60-V (вводится в действие по истечении десяти календарных дней после его первого официального опубликования).
