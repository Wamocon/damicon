# 252. Прекращение права собственности лица, которому в силу законов имущество не может принадлежать

1. Если по основаниям, допускаемым законами, в собственности лица оказалось имущество, которое не может ему принадлежать в силу законов, это имущество должно быть отчуждено собственником в течение одного года с момента возникновения права собственности на данное имущество, если иные сроки не предусмотрены законами. В случае, если имущество не будет отчуждено собственником в указанный срок, оно по решению суда подлежит принудительному отчуждению с возмещением собственнику стоимости имущества за вычетом затрат по его отчуждению.

2. Если в собственности гражданина или юридического лица по основаниям, допускаемым законами, окажется вещь, на приобретение которой необходимо особое разрешение, а в его выдаче собственнику отказано, эта вещь подлежит отчуждению в порядке, установленном для имущества, которое не может принадлежать данному собственнику.
