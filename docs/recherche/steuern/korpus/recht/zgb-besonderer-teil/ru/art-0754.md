# 754. Договор о переводе денег

1. По договору о переводе денег одна сторона (банк) обязуется по указанию другой стороны (клиента) перевести третьему лицу деньги без присвоения клиенту индивидуального идентификационного кода.

2. Порядок перевода денег банком без присвоения клиенту индивидуального идентификационного кода устанавливается законодательными актами, регулирующими банковскую деятельность.

Сноска. Статья 754 с изменением, внесенным Законом РК от 16.01.2026 № 259-VIII (вводится в действие по истечении шестидесяти календарных дней после дня его первого официального опубликования).
