# 151. Регистрация соглашений

1. Подписанные сторонами отраслевые, региональные соглашения с приложениями в десятидневный срок направляются для уведомительной регистрации.

2. Исключен Законом РК от 17.07.2025 № 213-VIII (вводится в действие по истечении шести месяцев после дня его первого официального опубликования).

3. Исключен Законом РК от 17.07.2025 № 213-VIII (вводится в действие по истечении шести месяцев после дня его первого официального опубликования).

Сноска. Статья 151 с изменением, внесенным Законом РК от 17.07.2025 № 213-VIII (вводится в действие по истечении шести месяцев после дня его первого официального опубликования).
