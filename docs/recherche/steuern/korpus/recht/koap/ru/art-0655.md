# 655. Неявка в суд для исполнения обязанностей присяжного заседателя

Неявка гражданина Республики Казахстан без уважительной причины по вызову в суд для исполнения обязанностей присяжного заседателя –

влечет предупреждение или штраф на физических лиц в размере десяти месячных расчетных показателей.

Сноска. Статья 655 с изменением, внесенным Законом РК от 11.06.2026 № 307-VIII (вводится в действие с 01.07.2026).
