# 898. Айыппұл салу туралы қаулыны орындау бойынша іс жүргізуді аяқтау

Айыппұл толық өндіріп алынған айыппұл салу туралы қаулы орындалғаны туралы белгі соғылып, қаулы шығарған органға (лауазымды адамға) қайтарылады.
