# 491. Азаматтық хал актілерін жазу қағидаларын бұзу

Некеге отыруға кедергі келтіретін мән-жайларды жасыру немесе азаматтық хал актілерін жазу органдарына жалған мәліметтер беру –

бес айлық есептік көрсеткіш мөлшерінде айыппұл салуға әкеп соғады.
