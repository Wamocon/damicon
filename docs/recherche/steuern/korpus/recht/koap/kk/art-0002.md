# 2. Әкімшілік жауаптылықтың негізі

Осы Кодекстің Ерекше бөлігінде көзделген құқық бұзушылық құрамының барлық белгілері бар іс-әрекет жасау әкімшілік жауаптылықтың негізі болып табылады.
