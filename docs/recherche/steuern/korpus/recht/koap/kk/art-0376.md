# 376. Сүректі есептік кеспеағаштан асып кететін мөлшерде дайындауға жол беру

Сүректі есептік кеспеағаштан асып кететін мөлшерде дайындауға жол беру –

лауазымды адамдарға үш жүз айлық есептік көрсеткіш мөлшерінде айыппұл салуға әкеп соғады.
