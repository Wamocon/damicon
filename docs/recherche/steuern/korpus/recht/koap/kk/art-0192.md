# 192. Арнаулы техникалық құралдарды сату тәртібін бұзу

Арнаулы жедел-іздестіру іс-шараларын жүргізуге арналған арнаулы техникалық құралдарды, жедел-іздестіру қызметін жүзеге асыруға уәкілеттік берілген мемлекеттік органдардан басқа, тиісті рұқсаты жоқ тұлғаларға сату –

қырық айлық есептік көрсеткіш мөлшерінде айыппұл салуға әкеп соғады.
