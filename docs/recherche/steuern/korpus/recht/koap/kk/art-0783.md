# 783. Дәлелдемелерді тексеру

Әкімшілік құқық бұзушылық туралы іс бойынша барлық жиналған дәлелдемелер мұқият, жан-жақты және объективті тексеруге жатады. Тексеру алынған дәлелдемелерді талдауды, оны басқа дәлелдемелермен салыстыруды, қосымша дәлелдемелер жинауды, дәлелдемелерді алу көздерін тексеруді қамтиды.
