# 915. Мүліктік залалды өтеу бөлігінде қаулыны орындау

Осы Кодекстің 59-бабына сәйкес өндіріп алуға жататын мүліктік залалды өтеу бөлігінде әкімшілік құқық бұзушылық туралы іс бойынша қаулы заңнамада белгіленген тәртіппен орындалады.
