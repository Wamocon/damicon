# 591. Көлік құралын басқару кезінде жүргізушінің телефонды не радиостанцияны пайдалануы

1. Көлік құралын басқару кезінде жүргізушінің телефонды не радиостанцияны пайдалануы –

бес айлық есептік көрсеткіш мөлшерінде айыппұл салуға әкеп соғады.

2. Осы баптың бірінші бөлігінде көзделген, әкімшілік жаза қолданылғаннан кейін бір жыл ішінде қайталап жасалған әрекет –

он айлық есептік көрсеткіш мөлшерінде айыппұл салуға әкеп соғады.

Ескертпе. Көлік құралын басқару кезінде телефонды не радиостанцияны тыңдауышты немесе қатты дауысты байланысты қолдану арқылы пайдалануға рұқсат етіледі.
