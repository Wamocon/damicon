# 186. Сақтандыру немесе зейнетақы жинақтарының құпиясын не микрокредит беру құпиясын сақтау міндетін бұзу

Кәсіптік немесе қызметтік жұмысына байланысты сақтандыру немесе зейнетақы жинақтарының құпиясын немесе микрокредит беру құпиясын қамтитын мәліметтер өзіне белгілі болған тұлғаның олардың иесінің келісімінсіз бұларды сақтау міндетін бұзуы –

елу айлық есептік көрсеткіш мөлшерінде айыппұл салуға әкеп соғады.
