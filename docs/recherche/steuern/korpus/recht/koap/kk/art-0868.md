# 868. Заңды тұлғаларға зиянды өтеу

Әкімшілік құқық бұзушылықтар туралы істерді қарауға уәкілеттік берілген органның (лауазымды адамның) заңсыз әрекеттерімен заңды тұлғаларға келтірілген зиянды мемлекет толық көлемде және осы тарауда белгіленген мерзімдерде қалпына келтіруге тиіс.
