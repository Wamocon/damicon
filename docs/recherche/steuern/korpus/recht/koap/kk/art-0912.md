# 912. Құрылысты мәжбүрлеп бұзу туралы қаулыны орындау бойынша шығыстар

Заңсыз тұрғызылып жатқан немесе тұрғызылған құрылысты мәжбүрлеп бұзып тастау құқық бұзушының есебінен жүзеге асырылады.
