# 379-бап. Ұтыстар түріндегі кіріс

Осы Кодекстің 21-бабының 17) тармақшасында айқындалған, төленген (төлеуге жататын) ұтыстар салық салуға жататын ұтыстар түріндегі кіріс болып табылады.
