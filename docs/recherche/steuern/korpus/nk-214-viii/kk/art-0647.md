# 647-бап. Салықтық кезең

Салықтық кезең осы Кодекстің 358-бабына сәйкес айқындалады.

5-параграф. Қалааралық және (немесе) халықаралық телефон байланысын, сондай-ақ ұялы байланысты бергені үшін төлемақы
