Прочие

Поиск налогоплательщиков
Сервис предназначен для поиска налогоплательщиков ФЛ, ИП, ЮЛ, при поиске ЮЛ имеется возможность просмотра информации о платежах юридических лиц

Предстоящие платежи для физических лиц

Онлайн бронирование
Если Вы хотите зарезервировать время посещения органа государственных доходов, согласно графику их работы

Сведения об отсутствии (наличии) налоговой задолженности
Сервис предназначен для поиска сведений об отсутствии (наличии) налоговой задолженности по заданным критериям

Поиск налогоплательщиков, имеющих право на применение льгот
Сервис позволяет загрузить информацию по налогоплательщикам, имеющих право на применение льгот

Поиск неблагонадежных налогоплательщиков
Сервис предназначен для поиска неблагонадежных налогоплательщиков, а также пользователь имеет возможность выгрузить списки неблагонадежных налогоплательщиков по Республике Казахстан, по областям г.г. Астана, Алматы

Реестр плательщиков НДС
Сервис предоставляет возможность пользователям произвести запрос на наличие налогоплательщика Республики Казахстан, зарегистрированного в качестве плательщика НДС

Экспресс-помощь
Сервис содержит онлайн-тесты как зарегистрировать свой бизнес, как получить ИИН нерезидентам, какую налоговую отчетность Вы должны представлять, как провести зачет или возврат излишне/ошибочно уплаченной суммы налога, платы, госпошлины или сбора

Проверка контрольного чека по регистрационному номеру контрольно-кассовой машины
Сервис позволяет осуществить поиск контрольного чека по ИИН/БИН и регистрационному номеру контрольно-кассовой машины.

Портал проверяет по указанным критериям в базе данных наличие, либо отсутствие ККМ

Поиск налогоплательщиков, находящихся на стадии ликвидации
Сервис содержит данные о налогоплательщиках, находящихся на стадии ликвидации

Поиск налогоплательщиков, сделки с которыми совершены без фактического выполнения работ, оказания услуг, отгрузки товаров
Сервис позволяет узнать информацию о налогоплательщиках, сделки (операции) с которыми совершены без фактического выполнения работ, оказания услуг, отгрузки товаров

Ввод и печать форм платежных документов
Сервис позволяет налогоплательщикам набрать и распечатать платежное поручение и (или) квитанцию по уплате налогов и других обязательных платежах в бюджет

Онлайн-оплата налогов и других платежей в бюджет

Поиск возвращенных уведомлений

Поиск документа, подтверждающего резидентство РК

Проверка чека оплаты

Реестр саморегулируемых организаций
Сервис позволяет узнать информацию о саморегулируемых организациях, подавших уведомление о начале деятельности в Комитет государственных доходов Министерства финансов Республики Казахстан.

Сведения о приостановлении (продлении, возобновлении) представления налоговой отчетности и об отзыве налоговой отчетности

Расчет налога на транспорт
Расчет суммы налога на транспорт осуществляется на основе данных, введенных пользователем и значений ставок налога, определенных Налоговым кодексом Республики Казахстан

Расчёт индивидуального подоходного налога
Расчет суммы ИПН с физических лиц, сервис выполнять расчет, как за полный, так и за неполный календарный месяц

Расчет пени
Расчет пени осуществляется на основе данных, введенных пользователем и значений ставок рефинансирования, определенных Налоговым кодексом Республики Казахстан

Кабинет налогоплательщика
Кабинет налогоплательщика предоставляет возможность пользователям получить доступ к формам налоговой отчетности через сеть интернет с любого удобного для пользователя места. Формы содержат подробную справку и систему проверки заполнения, позволяющую быстро и корректно их подготовить

Сопроводительные накладные на нефтепродукты (СНН)
Web-приложение для оформления, получения, выдачи, учета, хранения и представления СНН

Сопроводительные накладные на алкогольную продукцию (СНА)
Web-приложение для оформления и использования сопроводительных накладных при проведении операций по реализации (отпуску), перемещению, возврату, транспортировке этилового спирта и (или) алкогольной продукции юридическими и физическими лицами

Автоматизированная система таможенного и налогового администрирования АСТАНА-1
