API - интерфейс "Электронные счета-фактуры"

Дата публикации: 02.04.2018 19:22

Дата изменения: 17.12.2025 11:50

Уважаемые разработчики учетных систем и налогоплательщики!

Комитет государственных доходов МФ РК доводит до Вашего сведения, что в рамках реализации изменений нового Налогового кодекса Республики Казахстан, вступающих в силу с 1 января 2026 года , в информационной системе «Электронные счета-фактуры» внедрены новые функции, доступные для ознакомления и тестирования на сервере https://test3.esf.kgd.gov.kz:8443 .

Данные изменения включают:

Реализацию выписки ЭСФ за нерезидента.

В соответствии с обновленными налоговыми нормами, при приобретении работ и услуг у нерезидента, если местом реализации признается территория Республики Казахстан, резидент обязан выписать ЭСФ за нерезидента.

2. Внедрение механизма подтверждения/отклонения исправленных, дополнительных ЭСФ и отзыва ЭСФ получателями-плательщиками НДС.

Подробнее с данными процессами можно ознакомиться по ссылке https://kgd.gov.kz/sites/default/files/ftpdata/ESF/ИС ЭСФ_Памятка_подтверждение_отклонение ЭСФ плательщиками НДС 2.docx .

Комплект разработчика (SDK c обновлениями) доступен для скачивания на сайте КГД https://kgd.gov.kz/sites/default/files/ftpdata/ESF/esf-sdk-2025.zip .

В случае возникновения вопросов просим обращаться на электронную почту esfsd@kgd.minfin.gov.kz или по номеру телефона +7 (7172) 72-51-61
