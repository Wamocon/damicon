ПРЕСС-РЕЛИЗ Об изменении метода аутентификации по API

Дата публикации: 07.03.2023 16:17

Дата изменения: 07.03.2023 16:19

Уважаемые налогоплательщики!

Комитет государственных доходов МФ РК доводит до Вашего сведения, что в связи с переходом НУЦ РК на криптографический стандарт СТ РК ГОСТ Р 34.10-2015 (далее – ГОСТ 2015) и отказа от ключа аутентификации на алгоритме RSA, в Информационной системе электронных счетов-фактур (далее – ИС ЭСФ) был изменен метод аутентификации по API и на веб-портале для ключей ГОСТ 2015.

Измененный метод аутентификации доступен с 03.03.2023 на продуктивном https://esf.gov.kz:8443 и тестовом https://test3.esf.kgd.gov.kz:8443 серверах ИС ЭСФ. На данных серверах будет поддерживаться два метода аутентификации (текущий и новый для ГОСТ 2015) до 31 июля 2023 года.

Просим ознакомиться с измененным методом аутентификации и учесть данные изменения в своих учетных системах в срок до 31 июля 2023 года. С 1 августа 2023 года текущий метод аутентификации для ключей ГОСТ 2015 будет недоступен в ИС ЭСФ.

Обновленный комплект разработчика (SDK c измененным методом аутентификации) доступен для скачивания на сайте КГД https://kgd.gov.kz/ru/content/api-interfeys-web-prilozheniya-elektronnye-scheta-faktury-1
